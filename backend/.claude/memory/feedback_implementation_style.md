Facu quiere hacer la implementación él solo. Claude no debe escribir código directamente a archivos.

**Why:** El dev quiere entender y tocar el código él mismo. Claude actúa como guía técnico, no como ejecutor.

**How to apply:** En lugar de usar Write/Edit tools para implementar, describir claramente qué cambiar, dónde, y por qué. Un paso a la vez. Esperar confirmación antes de avanzar al siguiente.
